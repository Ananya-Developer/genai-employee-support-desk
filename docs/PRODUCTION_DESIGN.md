# Production design note

For 10,000 requests/day containing personal information, I would deploy the Spring gateway and Python evidence engine as separately scalable containers on a managed Kubernetes or serverless-container platform, fronted by an API gateway. Files would land in encrypted object storage through short-lived upload URLs; the synchronous assessment path would become an asynchronous workflow backed by a durable queue. PostgreSQL would store batch/item state, idempotency keys, policy versions and audit metadata. Workers would process items independently so poison documents cannot block a batch.

The policy corpus would move to a versioned, access-controlled policy service. Retrieval would use an index that stores tenant/role/effective-date metadata and enforces that metadata before semantic search. Model traffic would use an enterprise provider endpoint, strict structured-output validation, bounded deadlines, no hidden retries, and redaction/minimization before any external call. Raw employee documents would never be logged. Secrets would live in a managed secret store; service-to-service calls would use workload identity or mTLS.

The largest risks are cross-tenant evidence leakage, prompt injection, PII exposure, duplicate payments caused by downstream retries, policy-version drift, partial outages, unbounded model latency/cost, and ambiguity in the approval system. I would add encryption, least-privilege IAM, retention/deletion controls, immutable audit events, per-tenant metrics, distributed tracing, dead-letter handling, rate limits, SLOs, alerts, dependency circuit breaking, and explicit human-review queues.

Before committing to a delivery date I would clarify data residency/retention, tenant scale, peak batch size, document-size/type limits, claims-history ownership, exact approval-system API and idempotency semantics, policy-authoring/versioning ownership, required audit retention, model-provider restrictions, human-review SLA, disaster-recovery targets, and whether the business expects decision support only or any future automated approval/payment action.
